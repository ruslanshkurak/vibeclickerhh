# VibeClickerHH 🚀 — Умный бот автооткликов на hh.ru (С ИИ и Без ИИ)

**Полностью бесплатный и открытый инструмент для автоматизации поиска работы на HeadHunter (hh.ru).**

**VibeClickerHH** — это мощный автокликер и ассистент для соискателей. Бот автоматически ищет вакансии по вашим критериям, проводит интеллектуальный скоринг (оценку соответствия требований вакансии вашему опыту в резюме по шкале от 1 до 10) и отправляет персонализированные сопроводительные письма, написанные ИИ под каждую конкретную вакансию.

> 💡 **Можно использовать и БЕЗ ИИ!** Если вы не хотите использовать Google Gemini API, бот работает как быстрый традиционный автокликер по стандартному шаблону отклика.

*Больше не нужно вручную просматривать сотни вакансий и писать шаблонные письма — доверьте рутину автоматике.*

---

## ✨ Основные возможности
* 🧠 **Умный скоринг:** ИИ (Google Gemini) оценивает вакансии по шкале от 1 до 10 на основе вашего резюме и отсеивает нерелевантные.
* ✍️ **Генерация сопроводительных писем:** Уникальное письмо под требования каждой вакансии.
* ⚡ **Работа БЕЗ ИИ:** Возможность отключить ИИ-оценку и откликаться на все вакансии по вашим поисковым фильтрам.
* 🛑 **Гибкие фильтры:** Черные списки работодателей, исключение нежелательных слов в названии и грейдов (например, стажер/junior/lead), выбор региона.
* 🛡️ **Безопасность:** Имитация действий человека, случайные задержки и автоматический пропуск проблемных страниц.
* 📊 **Интерактивная аналитика:** Встроенный локальный дашборд воронки откликов для отслеживания статистики приглашений и просмотров.
* 🖥️ **Удобный GUI:** Простая настройка всех параметров через графическое окно.

## ⚡ Быстрый запуск для Windows (Без установки Python)

Если вы не хотите устанавливать Python и настраивать окружение:
1. Перейдите в раздел **[Releases](../../releases)** на GitHub.
2. Скачайте последний релиз **`VibeClickerHH.exe`**.
3. Запустите `.exe` файл и следуйте подсказкам в графическом интерфейсе.

## 🛠️ Запуск из исходного кода (Python)

### 1. Требования
* Установленный **Python 3.10** или выше.
* Аккаунт на **hh.ru** (вход выполняется один раз через окно браузера для сохранения сессии).
* *(Опционально)* Ключ **Gemini API** (можно получить бесплатно на [Google AI Studio](https://aistudio.google.com/)).

### 2. Установка зависимостей
Склонируйте репозиторий и установите библиотеки:
```bash
git clone https://github.com/ruslanshkurak/vibeclickerhh.git
cd vibeclickerhh
pip install -r requirements.txt
```

Установите системный браузер для Playwright:
```bash
playwright install chromium
```

### 3. Настройка конфигурации
1. Переименуйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Если планируете использовать ИИ, откройте файл `.env` и укажите ваш Gemini API ключ:
   ```env
   GEMINI_API_KEY=ваш_ключ_gemini
   ```

### 4. Подготовка резюме
Скопируйте пример резюме в рабочий файл:
```bash
cp resume.txt.example resume.txt
```
Откройте `resume.txt` и вставьте туда информацию о вашем опыте работы и технологиях. На основе этого текста ИИ будет оценивать вакансии. При запуске через GUI файл можно редактировать прямо во вкладке **«📝 Редактор резюме»**.

### 5. Запуск программы

#### Вариант A: Графический интерфейс (GUI)
```bash
python gui_app.py
```

#### Вариант B: Запуск через консоль
```bash
# Шаг 1. Авторизация на hh.ru (выполняется один раз)
python main.py --auth

# Шаг 2. Тестовый прогон (оценка и генерация писем БЕЗ отправки отклика)
python main.py --dry-run

# Шаг 3. Боевой автоотклик
python main.py --run
```

#### Вариант C: Веб-дашборд аналитики
```bash
python dashboard_app.py
```
После запуска дашборд доступен в браузере по адресу: **http://127.0.0.1:5000**
