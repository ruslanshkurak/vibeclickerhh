# VibeClickerHH.ru 🚀 — Умный бот автооткликов на hh.ru с ИИ Google Gemini

**Полностью бесплатный и открытый инструмент для автоматизации поиска работы на HeadHunter (hh.ru) с генерацией сопроводительных писем с помощью нейросетей.**

**VibeClickerHH** — это мощный автокликер и ассистент для соискателей. Бот автоматически ищет вакансии по вашим критериям, проводит интеллектуальный скоринг (оценку соответствия требований вакансии вашему опыту в резюме по шкале от 1 до 10) и отправляет персонализированные сопроводительные письма, написанные ИИ под каждую конкретную вакансию. 

*Больше не нужно вручную просматривать сотни вакансий и писать шаблонные письма — доверьте рутину автоотклику на базе ИИ.*

---

## ✨ Основные возможности
* **Умный скоринг:** ИИ оценивает вакансии по шкале от 1 до 10 на основе вашего резюме. Бот не будет откликаться на неподходящие вакансии.
* **Генерация сопроводительных писем:** Для каждой подходящей вакансии ИИ создает уникальное письмо, повышающее ваши шансы на просмотр.
* **Гибкие фильтры:** Черные списки работодателей, исключение нежелательных грейдов (например, стажер/junior/lead), выбор региона поиска.
* **Безопасность:** Бот имитирует действия реального пользователя, выдерживает паузы и имеет "ночной режим" для автоматического пропуска сложных страниц.
* **Интерактивная аналитика:** Встроенный локальный дашборд воронки откликов для отслеживания статистики приглашений и отказов.
* **Удобный GUI:** Простое графическое окно для настройки всех параметров бота без необходимости редактирования конфигов вручную.

## 🛠️ Инструкция по установке и запуску

### 1. Требования
* Установленный **Python 3.10** или выше.
* Аккаунт на **hh.ru** (вход выполняется через окно браузера один раз для сохранения сессии).
* Ключ **Gemini API** (можно получить бесплатно на [Google AI Studio](https://aistudio.google.com/)).

### 2. Установка зависимостей
Склонируйте репозиторий и установите библиотеки:
```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
pip install -r requirements.txt
```

Установите системные браузеры для Playwright:
```bash
playwright install
```

### 3. Настройка конфигурации
Переименуйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
Откройте файл `.env` и вставьте ваш API-ключ Gemini в строку:
```env
GEMINI_API_KEY=ваш_ключ_gemini
```

### 4. Подготовка резюме
Скопируйте пример резюме в рабочий файл:
```bash
cp resume.txt.example resume.txt
```
Откройте созданный файл `resume.txt` и вставьте туда информацию о вашем опыте работы, технологическом стеке и навыках. На основе этого текста ИИ будет оценивать вакансии. Если вы запустите программу без этого шага, она автоматически скопирует шаблон и попросит заполнить его.

### 5. Запуск
Вы можете запустить приложение с графическим интерфейсом:
```bash
python gui_app.py
```
Или запустить бота напрямую через консоль:
```bash
# Шаг 1. Выполните авторизацию на hh.ru (один раз для сохранения сессии)
python main.py --auth

# Шаг 2. Запуск в режиме тестирования (оценка вакансий и генерация писем БЕЗ отправки отклика)
python main.py --dry-run

# Шаг 3. Полноценный автоматический запуск автоотклика
python main.py --run
```

Для просмотра веб-интерфейса аналитики (дашборда) выполните:
```bash
python dashboard_app.py
```
После запуска дашборд будет доступен в браузере по адресу: **http://127.0.0.1:5000**
