# 🚀 Руководство пользователя — VibeClickerHH.ru

**VibeClickerHH.ru** — умный ассистент для автоматизации поиска работы и откликов на вакансии на сайте hh.ru с использованием искусственного интеллекта Google Gemini.

Бот самостоятельно ищет вакансии, сопоставляет требования работодателя с вашим резюме, оценивает совместимость по шкале от 1 до 10 и автоматически отправляет отклики с уникальными сопроводительными письмами. Также поддерживается работа в обычном режиме без ИИ по готовому шаблону.

## 1. 🔑 Получение API-ключа Gemini

Для ИИ-оценки вакансий и автоматической генерации писем вам потребуется API-ключ Gemini:

1. Перейдите в **[Google AI Studio](https://aistudio.google.com/)** и авторизуйтесь под своим Google-аккаунтом.
2. Нажмите кнопку **"Get API key"**, затем **"Create API Key"** (в новом или существующем проекте Google Cloud).
3. Скопируйте созданный ключ и вставьте его в поле **Gemini API Key** во вкладке **«⚙️ Настройки бота»** в приложении (или укажите его в переменной `GEMINI_API_KEY` в файле `.env`).

> [!NOTE]
> Бесплатного лимита Google Gemini API (15 запросов в минуту) более чем достаточно для непрерывной и комфортной работы бота на протяжении всего дня.

## 2. ⚙️ Быстрый старт и настройка

При первом старте программы в корневой директории автоматически создаются следующие файлы:
* `.env` — файл настроек конфигурации (вы можете создать его вручную, скопировав `.env.example`).
* `resume.txt` — ваше текстовое резюме (копируется из шаблона `resume.txt.example`).
* `analytics.db` — локальная база данных SQLite для хранения истории откликов и аналитики.

### Пошаговая настройка для запуска:
1. **Резюме:** Откройте файл `resume.txt` (или перейдите во вкладку **«📝 Редактор резюме»** в GUI) и вставьте туда текст вашего резюме. Обязательно сохраните файл.
2. **API Ключ:** Вставьте ваш полученный `Gemini API Key` в настройках GUI или в файле `.env`.
3. **Авторизация:** Запустите бота. В открывшемся окне браузера Chromium один раз выполните ручной вход на hh.ru под своим аккаунтом. Браузер сохранит сессию в файл `session.json`, и при последующих запусках бот будет входить автоматически.

## 3. 🎮 Обзор интерфейса

Интерфейс приложения разделен на три удобные вкладки:

### Вкладка 1: 🎮 Панель управления
* **🚀 Боевой автоотклик** — запускает полноценный цикл: автоматический поиск вакансий, оценку совместимости, написание писем и отправку отклика работодателю.
* **🧪 Тестовый прогон (Dry-run)** — безопасный тестовый режим. Бот будет искать вакансии, оценивать их и писать сопроводительные письма в лог, но **не будет нажимать кнопку отклика**. Рекомендуется для проверки генерации писем перед боевым запуском.
* **⏹ Остановить работу** — завершение процессов и закрытие окон браузера.
* **▶️ Продолжить работу** — возобновление работы после паузы (например, если бот приостановил работу для ручного прохождения капчи).
* **📊 Открыть дашборд** — запускает локальный сервер аналитики (`http://localhost:5000`) со статистикой воронки откликов и текстами отправленных писем.
* **Лимиты запуска** — ограничения по числу откликов и максимальному времени работы за одну сессию.
* **Автономный режим (пропускать ошибки)** — если включен, бот при ошибках сети или капче не будет приостанавливать работу и ждать пользователя, а автоматически пропустит вакансию и пойдет к следующей.

### Вкладка 2: ⚙️ Настройки бота
* **Gemini API Key / Модель** — параметры нейросети (рекомендуется использовать быструю и точную модель `gemini-1.5-flash`).
* **Использовать ИИ для оценки вакансий** — если отключить, бот будет одобрять все вакансии подряд (балл 10/10) без использования API-ключа и ИИ-анализа.
* **Ключевые слова HH.RU** — поисковый запрос (например, "Golang developer") или **прямая ссылка на поиск** с сайта hh.ru со всеми вашими преднастроенными фильтрами (зарплата, опыт работы, график).
* **Регион поиска (ID)** — код региона на hh.ru (например, `113` — вся РФ, `1` — Москва, `2` — Санкт-Петербург).
* **Минимальный балл ИИ** — порог соответствия вакансии вашему резюме, ниже которого отклик отправлен не будет (рекомендуется выставлять `6`–`7`).
* **Исключить грейды / компании** — автоматическая фильтрация нежелательных вакансий по стоп-словам в названии (например, junior, lead) и черному списку компаний.
* **Использовать собственный шаблон вместо ИИ** — отправка фиксированного сопроводительного письма вместо генерации ИИ.

### Вкладка 3: 📝 Редактор резюме
Встроенный текстовый редактор для изменения файла `resume.txt` (первоисточник вашего опыта для ИИ).

## 4. 🧠 Алгоритм работы и режимы

При переходе на страницу каждой вакансии бот действует по следующему алгоритму:
1. **Первичный фильтр:** Бот проверяет название вакансии на наличие стоп-слов грейдов и проверяет черный список работодателей.
2. **Проверка дубликатов:** Проверка по базе данных `analytics.db`, не откликались ли вы на эту вакансию ранее. Если отклик уже был, вакансия пропускается.
3. **Оценка соответствия:**
   * **С ИИ:** Gemini анализирует текст вакансии на основе вашего резюме, выставляет оценку от 1 до 10 и дает краткое объяснение своего решения.
   * **Без ИИ:** Шаг анализа пропускается. Вакансия автоматически получает оценку 10/10 с пометкой "Оценка ИИ отключена".
4. **Порог оценки:** Пропуск вакансий, балл которых ниже установленного минимума.
5. **Сопроводительное письмо:**
   * **С ИИ:** Gemini генерирует уникальное сопроводительное письмо под стек и требования конкретной вакансии.
   * **Без ИИ (или шаблон):** Используется готовый текст из настроек шаблона.
6. **Отклик:** Ввод сгенерированного письма в поле, клик по кнопке отклика и сохранение результатов в базу данных `analytics.db`.

## 5. 🛡️ Рекомендации и безопасность

* **Лимиты hh.ru:** Чтобы избежать подозрений со стороны алгоритмов hh.ru и не получить временную блокировку аккаунта, рекомендуется отправлять не более **30–40 откликов в день**.
* **Качество откликов:** Держите минимальный балл ИИ не ниже **6–7** для отсева вакансий, под требования которых ваше резюме совсем не подходит.
* **Ручная проверка (Дашборд):** Время от времени заходите в дашборд аналитики (`http://localhost:5000`) и проверяйте вакансии со статусом **«Требует ручной проверки»**. Обычно это отличные вакансии, при отклике на которые hh.ru потребовал заполнить дополнительный тест или анкету. Бот не заполняет тесты сам, поэтому их нужно «дожать» вручную.
